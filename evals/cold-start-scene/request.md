使用 $rebuild-web-experience

网址：http://127.0.0.1:9381/reference/

范围：只重建 `#observatory` 的完整可见体验，包括背景、观测仪、记录条，以及从天空视野滚动到信号档案的过程。页面顶部的 NORTHLINE 导航、介绍和底部结束语不在范围内。

自定义：观测记录可增删、排序，编号、名称、类型、坐标、距离、曝光时间、说明和颜色可编辑；标题、说明文字、主色、档案色、运动强度和拖动手感可配置。修改这些配置后保留对应的画面与交互。

输出：在 `evals/cold-start-scene/reconstruction/` 新建可运行、可维护的独立前端工程。提供 ESM 的 `mount / update / pause / resume / destroy` 接口、演示页和独立最小宿主页复用示例，附运行和修改说明。保留范围内可见的指针、拖动释放、按钮、键盘及滚动交互；若重建了 GPU 绘制，交付可编辑的原生 shader 源码。组件应能脱离参考站点启动、更新数据、暂停恢复、销毁后再次挂载。
